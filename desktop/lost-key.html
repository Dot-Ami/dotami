DotAmi can't open your data

Your data file is encrypted, and its key can't be opened on this Windows account.

That happens when the Windows profile is reset, when an administrator resets your password, when the data folder came from another account or computer, or when the key file was deleted or moved.

Nothing was changed. If you deleted or moved database.key (beside the data file), put it back — it may be in the Recycle Bin — and start DotAmi again: everything comes back. Otherwise, a backup brings back what it holds: Restore from a backup… moves the locked data file and its key file into the backups folder (never deleting them) and restores the backup under a new key.

Windows' key store isn't answering right now, so your key may well be fine. Nothing is given up for that: restart Windows (or sign out and in again) and start DotAmi again. Restoring a backup is offered only when the key store answers and the key still can't be opened.
